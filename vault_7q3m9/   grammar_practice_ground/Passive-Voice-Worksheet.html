Simple Explanation (বাংলা সহ)

Read this before starting the activities

In Active Voice, the subject performs the action: The researcher conducted the experiment.

In Passive Voice, the action happens to the subject: The experiment was conducted by the researcher.

বাংলায়: Passive voice-এ কাজটি কে করেছে তার চেয়ে কাজটি হয়েছে — সেটি গুরুত্বপূর্ণ।

Basic Structure
Passive = Object + be + past participle
Active: People build many houses.
Passive: Many houses are built.
Passive Voice in Different Tenses
Present Simple: am/is/are + V3 → The report is written.
Past Simple: was/were + V3 → The bridge was built.
Present Perfect: has/have been + V3 → The project has been completed.
Future: will be + V3 → The results will be announced.

Examples:

  1. The teacher explained the lesson. → The lesson was explained by the teacher.
  2. They built the bridge in 2010. → The bridge was built in 2010.
  3. Scientists have discovered a new species. → A new species has been discovered.
  4. The government will launch the program. → The program will be launched.
